KV CELL UNLOCKER - INTEGRAÇÃO DHRU FINAL

1. Configure na SquareCloud:
TELEGRAM_TOKEN=...
ADMIN_PASSWORD=uma senha forte
PARTNER_API_URL=https://server1.unlockingclean.com/api/index.php
PARTNER_API_USER=seu usuario
PARTNER_API_KEY=sua chave

2. Autorize o IP público da hospedagem no fornecedor: Profile > API Access.
3. Abra /admin?p=SUA_SENHA
4. API DHRU > Buscar serviços no servidor.
5. Pesquise e clique Importar. O serviço abre na tela normal de edição.
6. Configure descrição, campos, margens, acréscimo mínimo, tutorial e mensagens.

A sincronização usa imeiservicelist. O processamento usa placeimeiorder quando o serviço possui provider_service_id. Como fornecedores DHRU podem variar o formato de CUSTOMFIELD, valide um serviço de teste antes de liberar vendas.
