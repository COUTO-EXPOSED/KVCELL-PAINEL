- `CHANGELOG_V2000.1.md`: resumo das alterações e limites.
- `V2000.1_RELEASE_NOTES.md`: este documento.

## Testes executados

- Teste de fumaça existente (`tools/smoke_test.py`): PASS, incluindo inicialização local, autenticação, cliente, OS, MDM e orçamento público.
- Verificação de presença dos arquivos Square Cloud (`squarecloud.app`, `start.sh`, `requirements.txt`): PASS.

## Deploy / banco de dados
1. Faça backup da base de dados atual e dos arquivos persistentes antes de atualizar.
2. Preserve as variáveis de ambiente atuais e o diretório de persistência configurado em Square Cloud.
3. Envie o conteúdo deste ZIP para a aplicação existente conforme o procedimento de atualização do Square Cloud; não apague o banco existente.
4. `squarecloud.app` continua com `MAIN=app.py` e `AUTORESTART=true`; `start.sh` continua executando `python3 app.py`.
5. Não há migração SQL nesta versão; os aparelhos adicionais usam o campo `details_json` já existente.

## Limitações importantes
- O teste de fumaça não valida a interface em navegador real nem o ambiente de produção Square Cloud.
- Os aparelhos adicionais são metadados dentro da ordem (`details_json`), não linhas independentes em `devices`. O aparelho principal continua usando os campos legados `device_id`/marca/modelo/IMEI.
- Não foi possível confirmar neste ambiente a persistência de aprovação/rejeição remota, links públicos em domínio de produção, nem todos os módulos administrativos. Não interprete o smoke test como certificação integral de todos os fluxos.
