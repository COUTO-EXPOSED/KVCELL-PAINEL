## Optional Telegram bot

Set these two environment variables in Square Cloud under **Variables de Ambiente** and restart the application:

- `TELEGRAM_BOT_TOKEN` — the bot token generated by Telegram's official `@BotFather`.
- `TELEGRAM_CHAT_ID` — the target group ID (often a negative number for supergroups).

Enter the variables as key/value pairs (or paste the complete `KEY=value` line if Square Cloud's field auto-splits it):

```text
TELEGRAM_BOT_TOKEN=PASTE_REAL_BOT_TOKEN_HERE
TELEGRAM_CHAT_ID=PASTE_GROUP_CHAT_ID_HERE
```

Replace both placeholders with the real values in the Square Cloud dashboard only. Never commit these example placeholders as working credentials.

To connect it:

1. Create a bot with `@BotFather` and copy its token directly into the Square Cloud `TELEGRAM_BOT_TOKEN` value. Do not paste the token into source code, chat messages, or this repository.
2. Add the bot to the intended group and grant permission to send messages.
3. Obtain the group's chat ID using a trusted Telegram bot-management method; set it as `TELEGRAM_CHAT_ID`.
4. Save both variables in Square Cloud and restart the app. Do not share a real token in a support request.

With both variables set, the bot receives login/logout events and activity summaries (timestamp, unit, user, action, module, record ID). Event details, passwords, and customer payloads are excluded. Failed login notifications are rate-limited per source address. The explicit Telegram action on an OS or quote shows a confirmation before sharing the customer's name, phone, description, and values with the group; it also returns a copyable client message. If Telegram is not configured, the same message remains available for copying without an external send.

The automated suite forces Telegram credentials off and does not contact Telegram. A real group delivery, BotFather token, group permissions, and Square Cloud environment configuration have not been verified.
