# Provisionamento MDM KV CELL

Use somente em aparelhos de propriedade/gestão autorizada e conforme o contrato do crediário.

## ADB
1. Instale o APK oficial do companion.
2. Em aparelho compatível e preparado para provisionamento, execute o script correspondente.
3. O Android pode exigir factory reset/estado novo para aceitar Device Owner.
4. Depois, leia o QR individual para vincular o contrato/token.

Os scripts não fazem bypass de FRP, bootloader ou qualquer proteção de segurança.
